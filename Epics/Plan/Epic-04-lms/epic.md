## Зачем этот эпик

Обучение сотрудников и клиентов через курсы, уроки и сертификаты. Эпик обеспечивает полный цикл онлайн-обучения, включая управление учебным контентом, отслеживание прогресса и выдачу сертификатов.

## Out of Scope

- LMS квизы (тесты внутри уроков) — Epic-16 (US-04.10)

---

## Технические решения

- **Иерархическая структура курса (Course -> Chapter -> Lesson -> LessonBlock)** — обеспечивает гибкое конструирование учебных материалов разного типа
- **Автоматическая генерация сертификатов при 100% прогрессе** — исключает ручную выдачу и гарантирует выполнение всех уроков
- **Выделение специализированных ролей CURATOR и LEARNER** — обеспечивает гибкое разграничение прав доступа к управлению и прохождению курсов

- [x] [US-04.2] ADMIN может назначать кураторов на курсы

## Definition of Done

- [ ] Все US из таблицы выше реализованы или явно перенесены в другой эпик с указанием куда
- [ ] Flyway-миграции добавлены и проверены на чистой БД
- [ ] Smoke-тесты покрывают happy path каждой US
- [ ] Секреты только в env vars / Fly secrets, не в коде
- [ ] Нет raw stack trace в ответах API (ошибки через ApiException + ErrorCode)
- [ ] CI/CD pipeline зелёный (все тесты проходят перед деплоем)
- [ ] Эпик задеплоен на прод и проверен вручную
