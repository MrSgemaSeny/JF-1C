## Зачем этот эпик

Без этого эпика слушатели проходят курсы без объективной проверки знания материала, а сертификаты выдаются только на основе просмотра уроков. Эпик внедряет механизм тестирования внутри уроков и блокирует выдачу сертификатов при неуспешной сдаче квизов.

## Out of Scope

- Базовая функциональность LMS (курсы, уроки, выдача базовых сертификатов) — Epic-04
- Сложные формы аттестации с ручной проверкой развернутых ответов куратором

---

## Технические решения

- **Привязка Quiz к сущности Lesson** — тестирование встраивается прямо в цепочку прохождения учебного контента урока.
- **Хранение попыток прохождения (QuizAttempt)** — фиксация ответов и расчёт итогового балла для каждого слушателя.
- **Валидация выдачи сертификата через статус квизов** — генерация сертификата блокируется до момента успешной сдачи всех обязательных тестов курса.

## Acceptance Criteria

- [ ] [US-16.1] CURATOR может создавать Quiz с указанием вопросов, вариантов ответов и правильного ответа
- [ ] [US-16.2] Quiz привязывается к соответствующему уроку (Lesson)
- [ ] [US-16.3] LEARNER может отправлять ответы и проходить квизы внутри урока
- [ ] [US-16.4] Результаты тестирования и итоговый балл сохраняются в БД
- [ ] [US-16.4] CURATOR видит статистику прохождения тестов слушателями
- [ ] [US-16.5] LEARNER не может получить сертификат без прохождения обязательных тестов
- [ ] [US-16.6] Frontend содержит готовую страницу для прохождения тестирования
