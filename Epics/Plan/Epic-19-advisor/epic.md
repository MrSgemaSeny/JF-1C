# Epic-19: Advisor Role

**Цель:** Роль старшего менеджера с полным обзором всех клиентов, задач и документов
**Домен:** Cross
**Роли:** ADVISOR
**Статус:** Done

## Реализовано
- [x] Роль ADVISOR в системе ролей (Role.java)
- [x] Advisor Overview -- сводная страница со всеми метриками
- [x] Advisor Workload -- нагрузка по сотрудникам
- [x] Полный доступ ко всем клиентам (не ограничен assignee)
- [x] Полный доступ ко всем задачам
- [x] Полный доступ к документам всех клиентов и сотрудников
- [x] Task Pool -- доступ к незаназначенным задачам
- [x] Chat -- полный доступ
- [x] Навигация в sidebar: Overview, Workload, Tasks, Clients, Task Pool, Documents, Chat
- [x] CrmAccessService -- ADVISOR проходит все проверки доступа

## Acceptance Criteria
- [x] ADVISOR видит всех клиентов компании
- [x] ADVISOR видит все задачи всех сотрудников
- [x] ADVISOR имеет доступ к документам любого клиента и сотрудника
- [x] Навигация содержит все необходимые пункты меню
