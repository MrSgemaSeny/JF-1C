## Зачем этот эпик

Подключение собственного домена zhanfinance.kz и настройка Cloudflare CDN для защиты веб-сервиса, обеспечения HTTPS-шифрования, ускорения работы фронтенда и корректной обработки IP-адресов пользователей.

## Out of Scope

- Настройка локального DNS-сервера
- Покупка доменов в других доменных зонах
- Настройка Cloudflare WAF Enterprise правил

---

## Технические решения

- **Cloudflare Pages вместо GitHub Pages** — глобальный хостинг фронтенда с автоматическим деплоем и интеграцией с CDN Cloudflare
- **Обработка CF-Connecting-IP header** — использование заголовка Cloudflare в ApiRateLimitFilter для корректного считывания IP-адреса пользователя за прокси
- **Cloudflare SSL** — шифрование трафика между пользователем и CDN без необходимости ручной ротации сертификатов
