## Зачем этот эпик

Без этого эпика компания не может эффективно управлять взаимодействием с клиентами, распределять задачи между сотрудниками и отслеживать процессы продаж по стадиям. Эпик обеспечивает полноценную CRM-функциональность с Kanban-доской, пулом задач, профилями клиентов и гибкой моделью доступа.

## Пользовательские истории

| ID       | Роль      | Хочу                                      | Чтобы                                              | Статус |
|----------|-----------|-------------------------------------------|----------------------------------------------------|--------|
| US-02.1  | EMPLOYEE  | вести задачи (создавать, добавлять подзадачи, комментарии, теги и метки) и брать задачи из Task Pool | эффективно выполнять работу по клиентам и не терять контекст | Done   |
| US-02.2  | ADMIN     | управлять стадиями воронки продаж (Stages), переназначать любые задачи и менять их параметры | оптимизировать воронку и равномерно распределять нагрузку | Done   |
| US-02.3  | CLIENT    | иметь профиль и видеть статус связанных задач | отслеживать ход выполнения работ без обращений в поддержку | Done   |
| US-02.4  | ADVISOR   | иметь полный доступ ко всем задачам и клиентам компании | отслеживать общие процессы и осуществлять экспертное сопровождение | Done   |
| US-02.5  | EMPLOYEE  | работать с Kanban-доской по стадиям и переназначать задачи из статуса LOST с автовозвратом в воронку | наглядно контролировать движение задач по стадиям | Done   |

## Технические решения

- **CrmAccessService** — централизованная служба проверки и изоляции прав доступа к задачам и клиентам для разных ролей (включая сквозной доступ для ADVISOR).
- **IDOR защита на batch-операциях** — проверка ownership и полномочий для каждого элемента при массовых манипуляциях с задачами.
- **PipelineSeederService через ApplicationReadyEvent** — сидинг начальных стадий воронки запускается строго после полной инициализации Spring-контекста, что устраняет race condition с Flyway-миграциями.
- **Task Pool reopening** — при назначении из пула задачи, находившейся в стадии LOST, она автоматически сбрасывается на первую OPEN стадию воронки.
- **Скрытие интерфейсных действий для отменённых задач** — для задач в финальных состояниях (LOST/CANCELLED) в UI отключаются и скрываются кнопки действий для предотвращения некорректных переходов.

## Acceptance Criteria

- [x] [US-02.1] EMPLOYEE видит только свои задачи после назначения, а незаназначенные задачи видны всем EMPLOYEE в Task Pool.
- [x] [US-02.1] Для задач поддерживается создание подзадач (subtasks), комментариев, тегов и пользовательских меток (user labels), а также история изменений.
- [x] [US-02.2] ADMIN имеет возможность настраивать стадии воронки (Stages) и перенаправлять любые задачи.
- [x] [US-02.3] CLIENT видит профиль и статус своих задач без доступа к внутренним комментариям и служебным данным.
- [x] [US-02.4] ADVISOR имеет сквозной полный доступ ко всем задачам и профилям клиентов.
- [x] [US-02.5] Kanban-доска корректно отображает задачи по стадиям, а назначение задачи из статуса LOST автоматически возвращает её на первую OPEN стадию.
- [x] [US-02.5] В интерфейсе скрываются кнопки действий для отменённых и закрытых задач (LOST/CANCELLED).
- [x] Batch-операции проверяют ownership каждого элемента (защита от IDOR).

## Definition of Done

- [x] Все US из таблицы выше реализованы или явно перенесены в другой эпик с указанием куда
- [x] Flyway-миграции добавлены и проверены на чистой БД
- [x] Smoke-тесты покрывают happy path каждой US
- [x] Секреты только в env vars / Fly secrets, не в коде
- [x] Нет raw stack trace в ответах API (ошибки через ApiException + ErrorCode)
- [x] CI/CD pipeline зелёный (все тесты проходят перед деплоем)
- [x] Эпик задеплоен на прод и проверен вручную

## Известные ограничения / технический долг

- `[INFO]` Изоляция доступа CRM реализована программно на уровне приложения через `CrmAccessService`, а не на уровне СУБД (Row Level Security).
- `[INFO]` При высоком объеме задач в одной стадии Kanban-доске потребуется клиентская виртуализация списка или пагинация по стадиям.
