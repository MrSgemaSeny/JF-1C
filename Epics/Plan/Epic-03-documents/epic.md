## Зачем этот эпик

Эпик предназначен для автоматизации генерации, хранения и управления бизнес-документами (АВР, шаблоны Word и PDF). Без этого эпика пользователям и сотрудникам приходится вручную составлять и передавать файлы, а также отсутствует централизованный доступ и категоризация документов по ролям.

## Out of Scope

- Интеграция с внешним облачным хранилищем (Cloudflare R2 / AWS S3)
- Электронная цифровая подпись (ЭЦП) документов
- Push-уведомления и e-mail рассылки о событиях документов

---

## Технические решения

- **OpenHTMLtoPDF + Thymeleaf** — генерация PDF-документов с полной поддержкой кириллицы из HTML-шаблонов
- **poi-tl** — генерация Word-документов (.docx) на основе шаблонов
- **Хранение файлов в БД (`app.storage.type=db`)** — использование таблицы `stored_files` для централизованного хранения файлов
- **DocumentDataLoader и OfficialDocumentTemplateSeeder** — выделенный отдельный сервис загрузки шаблонов, предотвращающий их повторную перегенерацию при старте приложения
- **Multipart upload ограничения** — ограничение 20MB на один файл и 25MB на HTTP-запрос
- **ZIP-архивация документов** — выгрузка клиентских и сотрудникских документов в едином ZIP-архиве
- **Per-file try/catch при загрузке** — локальная обработка ошибок на клиентской странице документов без сбоя загрузки всего списка
- **Валидация расширений на уровне загрузки** — блокировка опасных расширений (.exe, .sh, .js) до сохранения файла в систему

- [x] [US-03.1] Загрузка файлов проверяет размер (до 20MB на файл, 25MB на запрос) и блокирует опасные расширения (.exe, .sh, .js)
- [x] [US-03.2] PDF генерируется корректно с поддержкой кириллицы (OpenHTMLtoPDF + Thymeleaf)
- [x] [US-03.2] Генерация Word-документов АВР работает на базе poi-tl
- [x] [US-03.3] Фильтрация по папкам (Folder pills), источнику загрузки (uploadedByRole) и отображение метрик работают на страницах документов

- [x] [US-03.5] ADVISOR имеет полный доступ к документам всех клиентов и сотрудников
- [x] [US-03.6] Шаблоны документов (OfficialDocumentTemplateSeeder, DocumentDataLoader) не перегенерируются при каждом старте приложения

## Известные ограничения / технический долг

- `[WARNING]` Файлы хранятся в БД (`app.storage.type=db`), таблица `stored_files` — при росте объёма документов потребуется переход на внешнее облачное хранилище (Cloudflare R2 / S3)
- `[INFO]` Ограничение на размер загружаемого файла составляет 20MB (25MB на общий HTTP-запрос)
