## Зачем этот эпик

В текущем состоянии файлы хранятся в PostgreSQL (`app.storage.type=db`). Это работает на начальном этапе, но не масштабируется при росте объема файлов и увеличивает нагрузку на базу данных. Эпик обеспечивает перенос файлового хранилища в объектное хранилище Cloudflare R2, чтобы освободить ресурсы базы данных и обеспечить устойчивое масштабирование.

## Out of Scope

- Оптимизация и автоматическое сжатие медиафайлов при загрузке
- Прямая загрузка файлов клиентом в R2 через presigned URLs
- Поддержка альтернативных S3-провайдеров (AWS S3, MinIO)

---

## Технические решения

- **Абстракция StorageService** — интерфейс с реализациями для БД и R2, позволяющий переключать хранилище через параметр `app.storage.type`
- **S3 API Cloudflare R2** — использование стандартного S3-совместимого клиента для работы с бакетом R2
- **Скрипт миграции BLOB** — инструмент для последовательного экспорта байтовых данных из таблиц PostgreSQL в объектное хранилище R2 без простоя сервиса
