# Zhan Finance Platform (JF-1C)
### Полнофункциональная технологическая экосистема вместо аренды чужих CRM

**Zhan Finance Platform** — готовность 100% к эксплуатации. Индустриальная веб-платформа, созданная для полного замещения разрозненных SaaS-сервисов (Bitrix24, amoCRM, сторонний биллинг, отдельная LMS-платформа и мессенджеры). 

Система передаётся бизнесу целиком: со всеми правами на исходный код, схему базы данных, бизнес-логику и возможностью масштабирования без зависимости от сторонних вендоров и подписок.

---

## Главные Преимущества для Бизнеса

| Проблема стандартных SaaS (Bitrix24 / amoCRM) | Решение Zhan Finance Platform |
|---|---|
| Растущие ежемесячные платежи за каждого пользователя | Полное владение системой: 0 рублей абонентской платы за пользователей |
| Данные клиентов хранятся на чужих серверах | Собственная база PostgreSQL 17 с автоматическими бэкапами и аудитом |
| Жесткие рамки готовых коробочных решений | Гибкая модульная архитектура, полностью адаптированная под финансовый сервис |
| Разрозненные инструменты (CRM, чат, документы, курсы отдельно) | Единый личный кабинет с ролевой моделью для Клиентов, Сотрудников и Админов |

## Архитектура и Ключевой Функционал

### 🎯 CRM и Управление Задачами
- **Канбан-доска процессов**: Интерактивное управление сделками через drag-and-drop.
- **Shared Task Pool**: Очередь нераспределённых задач, позволяющая сотрудникам брать входящие обращения клиентов в работу без задержек.
- **Изоляция прав**: Строгое разграничение видимости задач по назначению и ролям.

### 💰 Биллинг и Генерация Счетов
- **Автогенерация PDF**: Формирование счетов на оплату и актов с полной поддержкой кириллицы.
- **Подписки и Регулярные Счета**: Автоматический учёт статусов разовых услуг и рекуррентных подписок.

### 📄 Документооборот и Шаблонизация
- Загрузка, безопасное хранение и генерация юридических документов по корпоративным шаблонам.
- Проверка прав доступа к каждому файлу на уровне бэкенда через `DocumentAccessService`.

### 💬 WebSocket Чат в Реальном Времени
- Мгновенный обмен сообщениями между клиентом и персональным бухгалтером.
- Архитектурная защита: проверка JWT-токена и ролей (`ADMIN`, `EMPLOYEE`, `CLIENT`) при подписке на каждый канал связи.

### 🎓 Встроенная LMS (Система Обучения)
- Конструктор учебных материалов: Курсы -> Главы -> Уроки -> Блоки (видео, тексты, презентации).
- Автоматический онбординг новых сотрудников и аттестация клиентов.

### 🛡️ Безопасность и Аудит Уровня Enterprise
- **Двухфакторная аутентификация и OAuth2**: Интеграция с Google Auth и поддержка 2FA.
- **Защита от утечек сессий**: Автоматическое аннулирование всех активных refresh-токенов при смене пароля.
- **Маскирование чувствительных данных**: Хеши паролей, токены и секреты автоматический скрываются меткой `[PROTECTED]` в системном аудите.
- **Rate Limiting**: Защита от брутфорса и DDoS на уровне API-фильтров.

### 🌐 Публичный Лендинг и Лидогенерация
- Готовый фронтенд для привлечения клиентов: описание услуг, тарифы, команда и интерактивные формы заявок с загрузкой файлов, сразу попадающие в CRM.

## Техническая Готовность Продукта

- **Backend**: Java 17, Spring Boot 3.4, Spring Security, JPA, Flyway (V1–V108 миграций), PostgreSQL 17.
- **Frontend**: React 19, TypeScript, Vite, Tailwind CSS v4, Feature-Sliced Design (FSD).
- **API**: Полностью версионированный REST API (`/api/v1/...`).
- **Тесты**: 56 автоматических unit и интеграционных тестов с 100% успехом прохождения.
- **Локализация**: Полная поддержка русского и английского языков (i18n).
